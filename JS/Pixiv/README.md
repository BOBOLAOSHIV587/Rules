# Pixiv 全局增强翻译 (Pixiverse Enhanced)

适配 Pixiv 8.9.2 等版本：深度融合 **Pix-Scripting** 的设计哲学与 Apple 原生系统规范，实现**全页面日文深度就地汉化**、**出版级双语小说沉浸阅读**、**AI 视觉多模态漫翻**，并在 App 内置 **0 依赖离线秒开设置中心**。

---

## 🌟 核心特性

1. **出版级双语小说沉浸阅读**：
   - **严格一一对应的段落对**：原文在上、对应译文在下（`<div class="translation-pair"><div class="original">原文</div><div class="translated">翻译</div></div>`）；
   - **清晰克制的视觉层级**：原文为主阅读内容（正常字号、颜色、行高）；译文为从属辅助内容（稍弱对比度、合适字间距），不堆叠巨大背景框或粗边框；
   - **真实翻译状态追踪**：准确区分「准备翻译」、「正在翻译 X / Y」、「部分完成 · A / B」、「翻译完成」，绝不假装完成；
   - **失败段落针对性重试**：遇到网络超时仅重试失败批次，不重新请求成功段落，不破坏已有排版；
   - **规约智能净化**：自动过滤正文中的台本商用授权、禁止转载、免责协议等杂乱条款；
   - **字体自由定制**：支持系统默认（苹方）、经典宋体（纸书质感）、优美楷体（古雅风格）、柔和圆体。

2. **统一 Apple SF Symbols 单色矢量图标系统**：
   - 彻底摒弃普通网页廉价 Emoji 与五颜六色彩块图标；
   - 采用苹果官方 SF Symbols 设计语言，统一 20x20 视窗、1.8px 描边与单色层级底色，线条粗细与文字视觉重量完全匹配。

3. **极简可靠的悬浮按钮总开关**：
   - **单一纯粹开关**：仅保留 `[悬浮按钮 开/关]`，关闭后 100% 不注入 DOM，不占内存，不挂监听；
   - **舒适稳定定位**：固定于右侧（`bottom: 150px`），坐落在点赞喜欢按钮上方，页面滚动绝不异常跳动；
   - **极速触控响应**：轻点即切换原文/双语翻译，长按 500ms 弹出设置中心；纯中文作品自动隐身不打扰。

4. **真实、完整的本地缓存管理**：
   - 拒绝写死虚假数字，精准遍历计算真实暂存字节数（字节级精确计算，自动换算 KB / MB）；
   - 实时展示条目总数与最近缓存时间（如“刚刚”、“5 分钟前”）；
   - 提供二次确认 ActionSheet 弹层，清理完成后显示「已释放 XX · 已删除 XX 条」真实反馈并即时归零；
   - 仅清理以 `pxtc_` 开头的翻译文本缓存，绝对不误删任何插件设置或 API 密钥。

5. **全页面 REST API 深度就地汉化**：
   - 拦截首页全景流（`POST /v1/home/all`）、推荐流（`recommended`）、排行榜（`ranking`）、作品详情（`detail`）、评论区（`comments`）、画师主页（`user`）、搜索与特辑（`spotlight`）；
   - **双重模型写回**：同时汉化外层数据与底层 `t.app_model`，首页大标题与简介 100% 呈现中文，彻底消除“点击查看更多弹窗”；
   - **评论区全语种就地翻译**：日文、韩文（Hangul）、英文等多语种自动转为中文呈现；
   - **2500+ 高频 Pixiv Tag 离线字典（0ms 响应）**：主标签改写为中文，副标签自动置空，彻底消除上下两行文字复读堆叠问题。

6. **本地脱机秒开设置中心 (0 外部依赖)**：
   - 彻底拔除对外部 GitHub Release / CDN 的网络依赖，完全由本地内存直接提供纯静态 HTML/CSS/JS 页面；
   - 即使断网离线，在 Pixiv 中点击帮助中心亦能 0ms 瞬间秒开设置面板。

## 🚀 安装与启用指南

1. **导入 Loon 插件**：
   - 在 Loon 中添加插件：
     `https://raw.githubusercontent.com/TomCatXue/MyCookieCenter/main/loon/PixivEnhanced.plugin`
2. **安装并信任证书**：
   - 开启 Loon MITM，并确保信任证书，Hostname 包含：
     `app-api.pixiv.net, app.pixiv.help, policies.pixiv.net`
3. **唤出设置中心进行配置**：
   - 打开 Pixiv App，进入「我的」-> 右上角「设置」-> 点击「帮助中心」；
   - 或者在任意小说阅读页长按右下角的悬浮按钮；
   - 页面将自动加载 **Pixiv 增强设置** 面板。
4. **开启使用**：
   - 刷新 Pixiv 首页或点进任意插画/漫画/小说，全界面日文将自动完成汉化！
